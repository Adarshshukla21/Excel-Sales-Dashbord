# 📊 Flipkart Sales Dashboard 2024

## 📌 Project Overview

This project presents an interactive Sales Dashboard created in Microsoft Excel to analyze sales performance, purchases, profit, and product-wise trends.

The dashboard helps users understand business performance using charts, slicers, Pivot Tables, and KPI metrics.

---

## 🎯 Objectives

- Analyze total sales, purchases, and profit
- Compare monthly sales performance
- Analyze product-wise sales
- Filter data by category
- Track important business KPIs

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## 📊 Key Metrics

- Total Sales: 942,677
- Total Purchases: 548,691
- Total Profit: 393,985

---

## 📈 Dashboard Features

- Category Filters
  - Automobile
  - Electronics
  - Fashion
  - Food
  - Healthcare

- Monthly Sales Analysis
- Product-wise Sales Analysis
- Profit Tracking
- Interactive Charts

## 🔍 Business Questions
